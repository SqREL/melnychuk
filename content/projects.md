## Notable Work

Throughout my career, I've worked on various large-scale systems and platforms:

### Advertisement Management Platform (Simulmedia)
Supporting and implementing features in a large microservice-based legacy application for US Linear TV, Streaming services, and gaming. Focused on performance optimization and on-call support.

**Tech Stack**: Ruby (Sinatra, Sequel, Rails), TypeScript, Microservices, AWS, Grafana, RabbitMQ, SQS

### Freelance Platform (TopTal)
Part of the core team developing a global freelance platform, responsible for:
- Large-scale zero-downtime data migrations
- Sidekiq workers refactoring across the project
- REST API to GraphQL migration
- Planning and implementing PoC for Service-Oriented Architecture with Kafka
- CI/CD improvements: Jenkins to GitHub Actions migration

**Tech Stack**: Ruby on Rails, PostgreSQL, Google Cloud, Kafka, Redis, Kubernetes

### Risk Management System (Svitla Systems)
Supporting data hub as single point of truth for supply-chain risk management:
- Improved full-text search performance on large, frequently-changing PostgreSQL databases
- Implemented web scraping tool for AI team learning data
- Integrated OpenID Connect SSO with Azure ecosystem

**Tech Stack**: Ruby on Rails, PostgreSQL, Microsoft Azure, TypeScript

### Insurance Platform (Matic)
Helping US homeowners reduce insurance costs:
- Developed email marketing tools that decreased yearly payment costs
- Ensured compliance with US data protection regulations
- Planned and implemented service-oriented architecture
- Team/Tech management: hiring, onboarding, mentoring

**Tech Stack**: Ruby on Rails, PostgreSQL, AWS, SQS, TypeScript, Docker, MongoDB
